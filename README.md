# SupportDesk Pro

A full-stack IT Support Ticket System built with React, Node.js, Express and MySQL.

## Features

- User registration and login (JWT authentication)
- Create, view and update support tickets
- Ticket status workflow (Open → In Progress → Resolved → Closed)
- Priority levels (Low, Medium, High, Critical)
- Dashboard with live statistics
- Filter tickets by status
- Responsive modern UI

## Tech Stack

**Frontend**
- React + Vite
- Tailwind CSS
- React Router
- Axios

**Backend**
- Node.js + Express
- MySQL
- JWT + bcryptjs
